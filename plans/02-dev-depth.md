# Plan: 深度增强

> 目标：从"简单的草图转 HTML"进化为"专业级 UI 设计协作工具"
> 按能力层递进：布局精度 → 生成质量 → 组件系统 → 协作能力

---

## Layer 1 — 布局精度增强

### 1.1 形状属性面板

**问题**：无法精确控制形状的位置、大小、标签等属性，全靠鼠标拖拽。

**方案**：
1. 选中形状后，右侧或画布下方弹出属性面板
2. 面板显示并可编辑：
   - 位置：left% / top%（相对画布百分比）
   - 尺寸：width% / height%
   - 标签：可从下拉选择（导航栏、卡片、按钮、头像等）或自定义输入
   - 层级：z-index 调整
3. 修改数值后实时更新形状位置和大小

**涉及文件**：`sketch-to-ui.html`
- 新增属性面板 HTML 结构（浮动面板或侧栏）
- 新增 `updatePropertyPanel()` / `applyPropertyChange()` 函数
- `canvas.on('selection:created/updated')` 触发面板更新
- `canvas.on('selection:cleared')` 隐藏面板

**预估工时**：3h

---

### 1.2 辅助对齐系统（Snapping）

**问题**：形状之间无法对齐，生成的布局描述不精确。

**方案**：
1. 拖拽/调整形状时，自动吸附到其他形状的边缘和中心线
2. 显示辅助线（红色/蓝色虚线）
3. 可吸附目标：
   - 画布边缘和中心线
   - 其他形状的上下左右边缘
   - 其他形状的水平/垂直中心线
4. 吸附阈值：5px，可在设置中调整
5. 工具栏添加吸附开关按钮

**涉及文件**：`sketch-to-ui.html`
- 新增 `findSnapPoints()`, `checkSnap()`, `drawGuidelines()` 函数
- 修改 `object:moving` 事件处理
- 新增辅助线渲染层（用独立 canvas 或 SVG overlay）

**预估工时**：4h

---

### 1.3 12 列网格可视化

**问题**：当前只有背景网格线，但用户不清楚形状对应哪些列。

**方案**：
1. 选中形状时，高亮显示其占据的网格列
2. 画布底部显示列号（1-12）
3. 拖拽形状时，实时显示"第 X-Y 列"的 tooltip
4. 设置面板中可切换网格列数（8/12/16）

**涉及文件**：`sketch-to-ui.html`
- 修改 `grid-bg` 样式，增加列号标注
- 选中形状时计算并高亮对应列
- 新增 `getColumnRange(obj)` 函数

**预估工时**：2h

---

## Layer 2 — 生成质量增强

### 2.1 Prompt 模板系统

**问题**：每次发给 AI 的 prompt 固定，无法针对不同场景优化。

**方案**：
1. 预设多套 prompt 模板：
   - "完整页面"（默认）：生成完整 HTML 页面
   - "仅布局框架"：只生成结构骨架，不含真实内容
   - "带交互动效"：生成的页面包含 hover、过渡动画等
   - "移动端适配"：生成响应式页面
   - "表单专用"：侧重表单元素和验证
2. 用户可选择模板或自定义模板
3. 模板保存在 localStorage

**涉及文件**：`sketch-to-ui.html`
- 新增模板选择 UI（下拉菜单或在风格选择旁）
- 新增模板管理（预设 + 自定义）
- 修改 `beautify()` 中的 `textPrompt` 构建逻辑

**预估工时**：2h

---

### 2.2 多模型对比

**问题**：无法对比不同模型或不同 prompt 的生成效果。

**方案**：
1. 保存最近 N 次生成结果（模型 + prompt + HTML + 缩略图）
2. 提供"历史版本"面板，可切换查看
3. 支持"对比视图"：左右分屏同时预览两个版本
4. 每个版本显示：模型名、风格、时间、字符数

**涉及文件**：`sketch-to-ui.html`
- 新增版本历史数据结构 `generationHistory[]`
- 新增历史面板 UI
- 修改 `beautify()` 成功后保存到历史
- 新增对比视图模式

**预估工时**：3h

---

### 2.3 AI 生成参数调节

**问题**：temperature 等参数写死，无法根据需要调节。

**方案**：
1. 设置面板增加高级参数：
   - `temperature`（0.0-1.0，滑块）
   - `max_tokens`（1024-16384，滑块）
   - `system prompt`（可自定义系统提示词）
2. 参数保存到 localStorage
3. 生成时使用自定义参数

**涉及文件**：`sketch-to-ui.html`
- 扩展设置 Modal UI
- 修改 `beautify()` 使用动态参数

**预估工时**：1h

---

## Layer 3 — 组件系统

### 3.1 预制布局模板

**问题**：每次都从零开始画，常见布局（如顶部导航+侧边栏+内容区）需要重复画。

**方案**：
1. 提供 8-10 套预设布局模板：
   - 博客/文章页：顶部导航 + Hero + 内容 + 侧边栏 + 页脚
   - 电商首页：导航 + Banner + 商品网格 + 推荐 + 页脚
   - Dashboard：顶部导航 + 侧边栏 + 卡片网格 + 图表区
   - 登录页：居中卡片 + 背景装饰
   - 落地页：导航 + Hero + 特性 + 价格 + CTA + 页脚
   - 社交媒体：导航 + 左侧菜单 + 中间信息流 + 右侧推荐
   - 搜索引擎：Logo + 搜索框 + 快捷入口
   - 作品集：导航 + 项目网格 + 关于 + 页脚
2. 工具栏添加"模板"按钮，弹出模板选择面板
3. 选择模板后自动填充画布形状
4. 用户可在模板基础上修改

**涉及文件**：`sketch-to-ui.html`
- 新增模板选择 Modal
- 每个模板定义为一组形状数据（type, left%, top%, width%, height%, label）
- 新增 `loadTemplate(templateData)` 函数

**预估工时**：3h

---

### 3.2 组件库拖放

**问题**：需要手动画矩形再标注为"按钮"或"卡片"，效率低。

**方案**：
1. 左侧或顶部添加可折叠的组件库面板
2. 组件类型：
   - 基础：按钮、输入框、复选框、开关
   - 容器：卡片、列表项、表格行
   - 媒体：图片占位、视频占位、图标
   - 导航：标签页、面包屑、分页器
3. 拖拽组件到画布，自动创建对应形状并设置标签
4. 每个组件有预定义的默认尺寸和标签

**涉及文件**：`sketch-to-ui.html`
- 新增组件库面板 UI（可拖拽元素）
- 实现拖放到 Fabric canvas 的逻辑
- 组件数据结构定义

**预估工时**：4h

---

## Layer 4 — 协作与工程化

### 4.1 多页面项目管理

**问题**：只能设计单个页面，无法管理多页面项目。

**方案**：
1. 侧栏添加页面列表（如：首页、关于、联系、详情页）
2. 每个页面独立画布，独立保存
3. 页面之间共享全局设置（风格、颜色变量）
4. 可一键导出所有页面为独立 HTML 文件
5. 页面之间可定义导航关系

**涉及文件**：`sketch-to-ui.html`（重构较大）
- 新增项目管理数据结构
- 新增页面列表面板
- 画布内容按页面隔离
- 批量导出功能

**预估工时**：6h

---

### 4.2 设计 Token 编辑器

**问题**：风格 Token（CSS 变量）写死在代码中，无法可视化调整。

**方案**：
1. 新增"主题编辑器"面板
2. 可视化编辑每个 Token：
   - 颜色变量用颜色选择器
   - 圆角、阴影等用输入框
   - 字体用下拉选择
3. 实时预览 Token 变更效果（右侧预览区随 Token 更新）
4. 可保存自定义主题，支持导入/导出 JSON

**涉及文件**：`sketch-to-ui.html`
- 新增主题编辑器 UI
- 新增 Token 实时预览逻辑
- 修改 `THEMES` 为可编辑结构
- 导入/导出 JSON 功能

**预估工时**：4h

## 总预估

| 层级 | 内容 | 工时 |
|------|------|------|
| Layer 1 | 布局精度 | ~9h |
| Layer 2 | 生成质量 | ~6h |
| Layer 3 | 组件系统 | ~7h |
| Layer 4 | 协作工程化 | ~10h |
| **合计** | | **~32h** |

## 推荐实施顺序

1. **先做 Layer 1**（形状属性面板 + 对齐吸附 + 网格可视化）— 提升核心体验
2. **再做 Layer 2**（Prompt 模板 + 生成参数调节）— 提升输出质量
3. **Layer 3**（预制模板 + 组件拖放）— 提升效率
4. **Layer 4**（多页面 + Token 编辑器）— 进阶能力，按需实施
